# Contributing to PrintBridge

Thanks for helping! Bugs and ideas go into [GitHub issues](https://github.com/Beauver/PrintBridge/issues) using the templates. For code, open a pull request into `dev`; [CLAUDE.md](CLAUDE.md) describes how the project is built and tested.

### Sign-off

Every commit needs a `Signed-off-by` line with your name and email, as in the [Developer Certificate of Origin](https://developercertificate.org/). It confirms point 1 and that you agree to these terms. `git commit -s` adds it:

```
Signed-off-by: Your Name <you@example.com>
```

The pull request template has a checkbox for these terms as well.
